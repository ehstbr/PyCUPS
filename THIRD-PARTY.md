# Third-party software

PyCUPS uses system-provided open-source components and does not vendor
their source code.

| Component | Purpose | License family |
|---|---|---|
| OpenPrinting CUPS | Print service and IPP operations | Apache-2.0 with exceptions |
| PyCUPS Python bindings | Python bindings for CUPS | GPL-2.0-or-later |
| pypdf | PDF inspection, combination, and page extraction | BSD-3-Clause |
| Poppler utilities | PDF preview rendering through `pdftoppm` | GPL-2.0-or-later |
| GTK 4 | Desktop toolkit | LGPL-2.1-or-later |
| Libadwaita | GNOME interface components | LGPL-2.1-or-later |
| PyGObject | Python GObject bindings | LGPL-2.1-or-later |
| libsoup 3 | Asynchronous HTTPS update-manifest requests | LGPL-2.1-or-later |
| PolicyKit | Explicit administrator authorization | LGPL-2.0-or-later |

The applicable licenses and copyright notices are supplied by the Ubuntu
packages that install these components.
