# Support

Before requesting help:

1. Read the [README](README.md), especially compatibility and the distinction
   between job history and retained spool files.
2. Confirm that you are running the latest release.
3. Search [existing issues](https://github.com/ehstbr/PyCUPS/issues).
4. Open the matching bug or feature template.

Always remove document contents, names, usernames, addresses, printer/network
details, and credentials from screenshots or diagnostics. Security problems
belong in the private process described in [SECURITY.md](SECURITY.md).
